Formas de agregar estilos a una pagina web (HTML)

Estilos en linea

Estos estilos se agregan directamente en el elemento HTML mediante el atributo Style

Este parrafo tiene un fondo agregado con estilos HTML

Estilos internos

Estos estilos se agregan en el archivo html, dentro del elemento style, este elemento debe estar dentro de la etiqueta head1

Estilos exernos

Estos estilos son los recmendados ya que ofrecen modularidad, mantenimiento, eficiencia, entre otras vemtajas para agregar una hoja de estilos externa dentro d la etiqueta <head> se va a utilizar la etiqueta <link>
