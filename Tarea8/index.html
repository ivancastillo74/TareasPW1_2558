Colores de Borde

Para que un elemento HTML podamos asignarle un color a su borde son necesarias 2 propiedades: border-style y border-color; adicionalmente se pueden modificar su tamaño utilizando border-size

Degradado de colores

En css se puede aplicar dos tipos de degradado de colores:

Degradado lineal

El degradado lineal, es una transicion de un color a otro de forma lineal

Degradado Radial

El degradado lineal, es una transicion de un color a otro de forma radial
